# 验收证据的提交边界

## GitHub 保留什么

- 产品源码、测试代码和必要的审计元数据。
- 当前构建/覆盖测试直接读取的四份冻结 `.json.gz` 基线；`.gitignore` 对它们显式放行。
- 简洁的验收结论、适用范围和未验证项。
- 历史已跟踪的文件保持原样，不通过本次整理重写历史或删除已有必要资产。

原始 stdout/logcat、逐轮 XML、截图、机器 runner 结果、临时快照及清理清单默认仅保留本地，不整批提交。未来确需新增版本化证据时，先完成内容与敏感信息核查，再增加精确的放行路径；不要强制加入整个证据目录。忽略规则不是安全扫描，也不会自动移除已经跟踪的文件。

部分历史报告中的 `evidence/` 引用属于本地留存路径，不代表 GitHub 上提供了对应原始材料。旧哈希索引描述采集时的快照；精简后的本地目录以本机保留策略和路径映射为准，不能借旧索引宣称所有历史原件仍在线可取。
