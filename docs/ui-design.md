## 视觉系统

暖白背景 `#F5F6F2`、白色卡片、森林绿 `#315B42`、浅绿 `#D2EE98`、暖橙 `#EA8B51`。12 / 16 / 20 / 24px 间距，卡片 17–20px 圆角，App 弹层 24px 圆角。手机内容两侧 20px 内边距，主要操作采用满宽按钮。字体使用系统中文字体；标题 25px、正文 13px、辅助信息 10–12px。价格用突出数字和清楚的币种。

手机统一使用约 58px 的标题栏：显示当前页面名或域名 / 资源名，详情页返回按钮也放在标题栏。正文不再重复标题、品牌名或宣传标语。右侧放搜索图标与页面主要操作（购买、添加资源、添加 DNS 等）；搜索框仅在点击后展开。资源卡片保持约 80px 的紧凑列表行。

Logo 是当前云上下文的入口。点击后菜单从左侧滑入，显示当前厂商、该厂商下的账号和其他厂商的连接状态；左滑、点击遮罩或 Escape 可以关闭。切换账号保留当前功能页，详情页切换时回到所属列表，避免跨账号保留旧资源。未接入厂商明确显示规划状态，不能切换到不存在的资源。

底部五个 Tab：总览 / 域名 / 资源 / 账单 / 账号。域名解析与资源详情是子页面，返回时保留所属 Tab。操作中心从顶部通知按钮和总览快捷入口进入。桌面把这套导航放在侧边栏，详情改为两栏，保留同一套名称和操作语义。

可点击原型刻意保留全部示例、演示报价标记。正式 App 应去掉设计入口、演示选项和模拟数据。原型是纯 HTML / CSS / JS，方便独立预览，并不代表生产页面应放在一个 JS 文件中。

## 交互流程

Android 标题栏搜索按当前页面限定范围：真实域名列表搜索当前账号已加载的 Zone，Workers 搜索已加载资源，操作记录搜索本机记录；更多域名仍需手动加载。提交后保留输入框与搜索条件，忽略关键词首尾空格，支持一键清空和取消搜索。Zone 详情、DNS 管理以及 R2／D1／KV 使用各自页面的操作和筛选，不显示无效的重复搜索入口。演示 DNS 支持名称、内容和类型搜索；演示购买页搜索候选域名。桌面 Ctrl / Cmd + K 全局搜索属于设计原型能力。

Android 系统返回先关闭账号抽屉或可见搜索；在 Zone 管理面板中回到原 Zone 和原标签，详情回到列表，创建／编辑表单取消编辑，预览返回草稿，正在加载时不取消编辑。KV／D1／R2 子页的系统返回优先退出私有编辑、预览或子页，写入期间不退出或自动重试。操作记录按当前账号合并任务与摘要后搜索，保留只读核对入口。DNS 表单数字字段使用数字键盘，「完成」仅收起键盘，不预览或提交；数字格式错误就地提示，保留原始输入，范围和 Schema 约束仍在预览前验证。连接表单的键盘「下一项」依次进入 Account ID 和 Token，「完成」收起键盘而不发起连接；Token 保持隐藏并关闭自动纠错。D1／KV／R2 已有专用创建入口时，不再显示打开旧通用说明的顶栏加号。

资源列表分别显示未读取、正在读取、失败重试与已读取空态；刷新时保留已有行，分页未完整时只描述已加载范围，不将当前空页表述为账号无资源。D1 结果页系统返回仅在没有编辑器、私有输入或待下载导出时一并释放私有会话；已有查询草稿、浏览过滤和导出仍保留，正在写入时继续禁止返回。DNS 的 TTL、端口和优先级等数字格式错误在字段内及预览入口使用同一可读名称，不改请求字段或可信验证规则。

1. 接入原型：账号 → 添加连接 → 模拟填写 `demo-token` → 验证结果 → 选择账号 → 总览。当前 Android：添加服务引导 → 打开 Cloudflare 官方 Token 页面 → 手填 Account ID／Token → 验证 → 本机加密保存。独立凭据后端与自动权限引导属于未来设计。
2. 域名购买：域名 → 购买 → 搜索 → 选择 → 检查最新报价 → 展示首年 / 续费价格、币种、期限、账号、默认付款方式 → 主动选择自动续费 → 勾选确认 → 注册任务 → 成功后配置 DNS。当前原型模拟检查和支付，不扣款。
3. 购买异常：选择「需补充资料」显示官方入口；选择「网络中断」进入结果待核对任务；选择「域名不可用」停止购买并重新搜索。禁止把网络重试等同于再下单。正式版另需实现报价过期、价格变化和账号资料未准备的状态。
4. DNS：点击已有记录 / 添加记录 → 编辑 → 校验类型与内容 → 展示新旧值及代理 / TTL → 确认保存 → 记录进入任务中心。正式版在云端读回验证后显示生效，保留 DNS 缓存传播提示。
5. Worker：资源 → Worker → 部署版本 → 选择历史版本 → 显示当前与目标版本和流量分配 → 确认切换 → 操作记录。代码回滚不意味着数据库、外部服务或绑定迁移可自动回滚。
6. 账单：费用预估 → 按产品构成 → 已结算账单 → 官方入口；预算设置达到 80% 时提醒。导出 CSV 明确标记预估、币种、期间和来源。

## 状态规范

| 状态                  | 产品行为                                            |
| --------------------- | --------------------------------------------------- |
| 首次接入 / 无资源     | 引导接入或创建，保留其他 Tab 可访问                 |
| 正在同步 / 缓存过期   | 显示更新时间与刷新状态；避免清空已有有效数据        |
| 权限不足 / 凭据过期   | 指出具体缺失权限与所属连接；可查看其他连接          |
| 厂商不支持 / 官方处理 | 说明范围，提供适用入口；无效操作不呈现为可点击购买  |
| 变更冲突              | 显示最新值与原计划差异，重新确认                    |
| 异步任务              | 关闭弹层后仍可从任务中心查看，不依赖页面常驻        |
| 结果未知              | 查询云端结果，禁止自动重复收费或破坏性操作          |
| 缺少费用              | 显示「暂不可用」及来源原因，不填 `$0`；用量仍可显示 |
| 多币种                | USD / CNY 各自合计；明确启用折算后才显示跨币种总计  |

## 交付与边界

`design-board.html` 提供八个可点击手机画面的设计总览；`index.html` 是响应式交互原型，包含额外 R2 和任务画面；`architecture.html` 是架构可视化。PNG 文件提供可分享静态稿。所有运行依赖均为浏览器内建能力，没有外部字体、图像或 CDN 依赖。

原型已提供模态框焦点限制、键盘 Escape、原生表单校验、图标标签和减少动画支持。Android 已有基础 Cloudflare API、连接持久化和平台凭据加密；目标产品 API、精细能力探测、后台同步、推送及完整无障碍验收仍待补齐，不能把原型支持直接视为原生验收。
