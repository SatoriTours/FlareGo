01 / 连接你的第一朵云

账号 → 添加连接 → 验证 Token → 发现账号与权限 → 选择账号 → 同步资源
权限不足：补充对应授权，其他可用模块仍然可访问。

02 / 从好名字到可访问的服务

域名 → 搜索 → 选择 → 最新报价 → 确认付款 → 注册任务 → 配置 DNS
网络中断：保留任务并核对结果；需补充资料：显示官方入口。

03 / 资源与费用保持可控

资源 → Worker 详情 → 部署版本 → 预览流量变更 → 确认切换 → 操作记录
账单 → 预估构成 / 已结算账单 → 设置预算 → 导出费用明细。
